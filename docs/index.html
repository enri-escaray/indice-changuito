    Cómo se calcula

    • Todos los días se consulta el precio online de cada producto de la canasta en Carrefour, Día, Jumbo, Disco, Vea y Más Online.
    • El índice usa el precio de lista, sin promociones temporarias, para medir inflación y no ofertas que empiezan y terminan. Las comparaciones entre supermercados usan el precio que se paga hoy, con promociones.
    • La variación de cada producto es la media geométrica de la variación en cada supermercado. Si un precio falta, se usa el último conocido durante hasta 7 días.
    • Cada categoría promedia sus productos y el índice general pondera las categorías. Las ponderaciones son provisorias.
    • No incluye carnes, frutas ni verduras frescas porque se venden por peso y no tienen un código de barras común.
